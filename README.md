# SMS Fraud UZ

Классификатор мошеннических SMS на узбекском (латиница) и русском языках и небольшое Streamlit-приложение для проверки сообщений.

Приложение показывает вероятность мошенничества и слова, которые сильнее всего повлияли на оценку (например, `заблокирована`, `перейдите`, `yutib oldingiz`).

## Данные

Открытых корпусов узбекских SMS нет, поэтому датасет синтетический: `generate_data.py` собирает 4 000 сообщений (по 2 000 в каждом классе).

- **Мошеннические** строятся как «предлог + призыв к действию». Предлоги: блокировка карты, выигрыш, «служба безопасности банка», «мама, срочно нужны деньги», компенсация от государства, посылка на таможне, кредит под 0%, штраф из налоговой. Призывы: ссылка на поддельный сайт, просьба продиктовать код из SMS, перевести деньги на карту, позвонить.
- **Обычные**: уведомления банков о покупках и пополнениях, коды подтверждения («никому не сообщайте»), доставка, напоминания об оплате, переписка с друзьями.

## Модель

TF-IDF по словам (1–2-граммы) и символьным n-граммам (3–5) плюс логистическая регрессия. Символьные n-граммы одинаково работают с кириллицей и латиницей и устойчивы к опечаткам.

## Оценка

Обычное случайное разбиение здесь бесполезно: сообщения одного шаблона попадают и в train, и в test, и любая модель получает около 100%. Поэтому используется **grouped 5-fold CV**: каждый вид сообщений целиком уходит либо в train, либо в test, и модель проверяется на видах мошенничества, которых не видела.

| Метрика | Значение |
|---|---|
| ROC-AUC | 0.998 |
| Accuracy | 0.890 |
| Precision (fraud) | 0.853 |
| Recall (fraud) | 0.993 |

Модель почти не пропускает мошенничество, но иногда срабатывает на обычные сообщения нового вида. Для фильтра с подсказкой «проверьте это сообщение» такой компромисс приемлем.

**Ограничения.** Данные синтетические, и на реальных SMS качество будет ниже. Следующий шаг — собрать и разметить настоящие сообщения.

## Запуск

```bash
pip install -r requirements.txt
python generate_data.py   # создать data/sms.csv
python train.py           # обучить и оценить модель, сохранить model.joblib
streamlit run app.py
```
